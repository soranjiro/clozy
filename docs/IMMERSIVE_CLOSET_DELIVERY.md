# 没入型クローゼット：実装状況

2026-11-01。ローカル実装。公開・デプロイは実施していない。

## 実装済み

- 旧ヘッダー・サイドバー・タブバーを取り除き、家具の側面操作と機能一覧に移行。
- 登録された実データからトップス、ボトムス、靴、長物、バッグ/小物、収納中へ配置。
- 横スクロール、キーボード左右、前後ボタン、位置スライダー、中央アイテムの拡大。
- 各レールは中央前後4着までをマウント。1000着でも全画像を同時に読み込まない。
- 写真索引は36着ずつ表示。名前/ブランド/色検索、カテゴリ/季節/収納/お気に入り、並べ替え、解除、ページ移動。
- 索引で選んだ服をレールの位置に表示し、取り出しダイアログへ接続。
- 手動コーデ、同カテゴリ入れ替え、ワンピースと上下の排他、別日付の着用記録、重複記録抑止。
- 登録・編集・一括追加・候補・カレンダー・分析・設定・パスキーロックは既存サービスを利用。
- 最新mainの見本26着/履歴99件の独立プレビュー、ChatGPT相談、PWAの商品URL下書き機能を統合して保持。
- 写真なしは既存SVG。写真更新/破損時の表示を修正。Blob URLを解放。
- ネイティブdialogのフォーカス制御、Escape、動きを減らす設定、320px画面に対応。

## 表現の範囲

現在のデータに服の3Dモデルがないため、写真/SVGをCSSの奥行き・回転・陰影で表示する実装。WebGLによる3Dモデル描画、カメラ移動、服の裏面、布シミュレーションは含まない。生成コンセプト画像を実データとして表示しない。

索引は仮想スクロールではなくページ分割。靴は横に送る棚で、コンセプトの2列3段トレーの完全再現ではない。ブラウザ履歴による空間状態の復元、保存済み配置、端末再起動後の選択復元は未対応。要件書の全項目が完了したことを示す文書ではない。
