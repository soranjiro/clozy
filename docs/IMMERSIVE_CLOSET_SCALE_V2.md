# Clozy：服が増えても使いやすいクローゼット v2

2026-11-01。既存の没入型UX設計への改訂提案。アプリ実装は未変更。

## 改善の中心

収納は「上部トップス・独立したボトムスレール・下部シューズラック」を維持。服の数に合わせて服を小さくするのではなく、見せる範囲を移す。常設ヘッダー・タブバーは置かない。

1. **全景で収納場所を把握**：各区画の代表的な服と続きがある端を表示。全所有物を同時に詰め込まない。
2. **レールで1着を選ぶ**：中央1着を正面、左右各3着を斜め、その先は側面にする。中央付近だけ間隔が開く。送り操作と選択操作は分ける。
3. **多い時は索引から飛ぶ**：虫眼鏡の取っ手を開くと写真の索引。検索・種類・季節・色・お気に入りで絞り、結果を選ぶと該当レールの位置へ戻る。
4. **靴はトレー単位で探す**：2列×3段程度を表示。棚内の縦送りで続きを閲覧し、選んだ一組だけ手前へ。外側の縦探索と競合しないよう、棚への接近中だけ棚内スクロールを有効にする。

## 所有数への対応

| 所有数の例 | 初期表示 | 探し方 |
| --- | --- | --- |
| 0〜20 | 適切な余白のある収納。空ハンガーから追加 | 見渡して選ぶ |
| 21〜100 | 各レールは一定の服サイズを維持 | 横送り＋種類ごとの仕切り |
| 101〜500 | 同じ表示密度、索引への入口を常時露出 | 検索・季節・種類から該当位置へ |
| 501〜1000以上 | 同じ操作構造、表示範囲のみ描画 | 仮想化された写真索引と直接ジャンプ |

この区切りは検証用の目安。件数増加によって突然画面構造や収納位置を変えない。1000件対応は目標であり実測済みではない。

## 迷子にしないルール

- レールに埋め込んだ小さな位置目盛りで現在位置を示す。実製品では操作時に「24 / 180」等の件数も表示する。画像のみ文字なしとする。
- 種類別の仕切りはユーザーが種類順を選んだ時に使用。色順・名前順では異なる意味の区切りを混ぜない。
- ソート順を勝手に変更しない。中央の服ID、区画、絞り込み、各区画の位置を保持する。
- 検索結果から服を開いて戻ると、索引の検索条件・位置へ復帰する。
- 季節外の服を自動で消さない。衣替え収納は明示操作。フィルター中は状態と全解除を確認できる。
- 新規追加後は登録した服を表示し、通常の並びに戻る操作を用意する。
- 長いレールを何百回もスワイプしなくても、索引・検索・区切りへのジャンプで到達できる。
- 削除や分類変更で中央IDが消えた場合は、直前の並びの隣接アイテムへ。空なら空状態を明示する。

## 視覚の改訂

明るいスモークオーク、濃い木の縁、シャンパン色の金属、リネン色の背板へ。暖かさを保ちながら黄かぶりを抑え、服の色と素材を主役にする。木の太い仕切りを減らし、服の周囲に空間を確保する。

同じ靴や服の複製で量を表さず、異なる服のシルエット・色・間隔で所有物の多様さを表現。操作アイコンは選択した服の近くに限定する。

## 操作・実装への追加

- レールの中央位置と選択状態は別管理。ドラッグ中のアイテムを勝手に詳細表示しない。
- 索引は検索入力とDOMの写真一覧。スクリーンリーダーとキーボードでも全件へ到達可能。
- 色は既存の自由入力データを尊重。色スウォッチは正規化できた色にのみ対応し、不明・その他も選べる。自動画像認識済みと見せない。
- `closet-projection`に区画別ID一覧、フィルター後件数、区切り位置を持たせる。全件の3Dインスタンスは生成しない。
- `RailScroller`は論理スクロール幅と表示範囲を分離。視界内＋前後2着のみモデルを読み込む。選択服は範囲外でも処理完了まで保持。
- `UtilityDrawer`に仮想化された写真索引を追加。絞り込み後も元データの収納先を保持し、検索ヒットから正しい区画へ移動。
- `ShoeRackScene`の棚操作には明示した接近/戻る状態を設ける。棚の端ではスクロールを閉じ込めず、外側へ戻れる。
- 位置目盛りは44px以上の押下領域を持ち、ドラッグ以外に前後/区切り移動も提供。

## 追加の受け入れ条件

- 20/100/500/1000件で服の最小表示サイズと操作領域を維持する。
- 500件中の指定服に、全レールを順送りせず検索から到達できる。
- 索引→服→戻るで検索文字列・スクロール位置・フォーカスが復元される。
- 同じカテゴリー500件、長い名前、写真なし、色未入力、収納中だけの状態でも破綻しない。
- 1000件と20件で初期モデルロード数が所有数に比例しないことを確認する。
- 小画面で靴棚の内部スクロールとクローゼットの縦移動が競合しないことを実機確認する。

画像：`concepts/immersive-closet/board-v2-scale.png`。4画面は全景、レール探索、写真索引、靴棚。静止コンセプトであり性能・操作の検証結果ではない。
